Chamber Designer

Colour ID (buttons & doors):
Syntax reference
registerChamber({
 name:'Title',  hint:'Text shown at the top of the screen',
 ops:[ ['#',x0,y0,x1,y1], ['W',x,y], ['S',2,15], ['E',26,15] ],   // 30 x 17 tiles, (0,0) = top-left
 cubes:[ [x,y] ],                 // cube spawn tile
 buttons:[ [x,y,id] ],            // floor button, id 0-3 (red, yellow, green, purple)
 doors:[ [x0,y0,x1,y1,id] ]       // opens while ALL buttons with the same id are pressed
});
ops characters:  #  solid wall      W  white portal wall     ~  acid
                 L  laser field (kills the player, cubes pass through)
                 S  start           E  exit                  .  empty (carve)
The outer border is solid by default. Paint over it with W to make portal walls on the edge.
Add the file as chambers/chamberNN.js and set CHAMBERS=NN in index.html.
