# Test-Chambers

A Portal 1 & 2 themed 2D puzzle game, similar to *Portal: Flash Version*.

## How to Play / Download
* **Single File:** The `test-chambers-standalone.html` file contains all the test chambers in a single, playable file.
* **Full Folder:** Alternatively, you can download the entire `test-chambers` folder, which separates the maps into individual files.
* **Via my [Deployment](https://dinorobotrocket.github.io/Test-Chambers/test-chambers/):** You may also go to my [deployment](https://dinorobotrocket.github.io/Test-Chambers/test-chambers/)

## Custom Maps & Modding
* **Custom Maps:** Instructions on how to create your own custom maps can be found inside the `README.txt` file.
* **Modding:** Feel free to mod the game! I actively encourage you to experiment with and modify the code.

I hope you enjoy!
